# Aurora EV safety baseline

This fictional, synthetic corpus is intentionally small enough to review by hand. It models an
electric-vehicle battery pack and contains no proprietary or customer information.

- `requirements.md` is the controlled requirement baseline.
- API seed data adds verification tests, hazards, cybersecurity threats and signed evidence
  placeholders.
- `REQ-BMS-001` and `REQ-CHG-001` have two revisions to exercise semantic comparison and impact
  traversal.

The S3 locations returned by the API are provenance examples. No private documents are bundled.
