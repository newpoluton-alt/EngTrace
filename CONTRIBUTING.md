# Contributing

1. Create a focused branch from `main`.
2. Run `make install`, then `make lint test eval`.
3. Keep the synthetic corpus free of confidential or customer data.
4. Add evaluation cases for retrieval, citation or guardrail behavior changes.
5. Explain schema and governance changes with an ADR under `docs/adr/`.

Security issues should not be opened as public issues; follow `SECURITY.md`.
